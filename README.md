## ✨ 特性

- **后端**：基于 .NET 10 的 Web API，支持 OpenAPI 文档
- **前端**：Vue 3 + TypeScript + Vite，现代化前端开发体验
- **测试**：前后端均配置单元测试框架（xUnit / Vitest）
- **CI/CD**：GitHub Actions 自动化构建、测试和代码质量检查
- **代码规范**：统一的 .editorconfig 配置和 ESLint 规则
